# Transmission Remote

Android-клиент для управления Transmission по RPC (Kotlin + Jetpack Compose).

## Возможности
- Несколько серверов: общий список торрентов или фильтр по серверу, статус и скорость каждого сервера
- Список: поиск, фильтры по статусу, сортировка, множественный выбор (долгое нажатие), пауза/старт, проверка, реанонс, очередь, перемещение, удаление с данными или без
- Добавление: magnet/URL (несколько сразу), `.torrent` файлы, открытие `magnet:` и `.torrent` из других приложений, папка, приоритет, метки, «на паузе»
- Детали торрента: инфо, файлы (выбор, приоритеты, переименование), пиры, трекеры (добавить/удалить), лимиты, рейтинг, приоритет, метки
- Настройки сервера: шифрование (обязательное / предпочитать / разрешить), порт и проверка порта, DHT/PEX/LPD/µTP, лимиты скорости и альт. лимиты с расписанием, папки, очереди, блоклист
- Статистика и свободное место на диске
- Уведомления о завершённых загрузках (проверка в фоне ~ раз в 15 минут)
- Работает по HTTP в локальной сети (cleartext разрешён)

## Сборка через GitHub
1. Создайте репозиторий и запушьте содержимое этой папки в ветку `main`.
2. Вкладка **Actions → Build APK** запустится сама (или нажмите *Run workflow*).
3. APK: в конце запуска, раздел **Artifacts** → `TransmissionRemote-apk`.
4. Для публикации в Releases: `git tag v1.0.0 && git push origin v1.0.0`; APK появится на странице релиза.

APK подписывается debug-ключом — для личного использования достаточно. Чтобы обновляться поверх без переустановки, всегда собирайте через один и тот же репозиторий.

## Локально
Откройте папку в Android Studio (Koala или новее, JDK 17) → Build → Build APK(s).

## Замечания
- Логин/пароль серверов хранятся в DataStore приложения (внутреннее хранилище, без шифрования).
- Transmission должен разрешать доступ с адреса телефона (`rpc-whitelist` в settings.json или отключённый whitelist).
